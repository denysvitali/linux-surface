functionality. No physical interaction was tested.

This differs from I, where the raw device existed and IPTSD timed out while
opening it. J never reached the daemon startup boundary, so the installed
userspace restart policy was **not exercised**. This is neither a policy
failure nor an input-startup pass. The relationship, if any, to the audio
stage remains unestablished. No input restart, rebind or recovery was
performed for this independent review.
