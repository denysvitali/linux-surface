**Observed:** at22.279s OF cannot translate the CDSP DMA window to CPU addresses.
The context-bank joins IOMMU group12, but its complete translated-window guard
rejects setup withEINVAL; no capability device/query or workload is reached.
ReturningENODEV after child removal causes repeated populate/probe failures and
large journals. The query preflight stops with an assertion; no remote fetch.

unhandled SMMU fault is found. Automatic return captures logs at938.93s and
verifies known-good payloads/default/empty pending selection.

**Cause/next:** `of_bus_default_match()` requires an explicit `#address-cells`.
The CDSP remoteproc parent lacks it, so DMA translation from the new GLINK
range cannot find a parent bus; inherited counts do not fix bus matching.
Add explicit2/2 parent cells and keep a rejected capability-only channel bound
without publishing a device, preventing the remove/populate storm. Retain
all address/session guards and expose the specific failed values. Do not
guess another SID or weaken the window. B07 remains open; next trial uses this
correction and the same capability-only test, before any process or compute.
The correction is committed as `9a48c20f24e7` (binding `8fc2fce7fb16`);
incremental modules/DT build and the explicit-parent staging guard pass.
