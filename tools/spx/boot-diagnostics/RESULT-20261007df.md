# DF: guarded retained-SLIM s2idle (prepared WIP, untested)

**Problem:** DE's audio-loaded controller rejects system sleep because forced
runtime suspend reaches the intentional `-EBUSY` power-collapse guard. Firmware
core collapse with live PIO accesses historically wedges the CPU; removing that
protection is not justified.

**Change:** `23c8f8e37a76` adds a readonly, default-off `spx_s2idle_retain` option.
Only Surface Pro X and s2idle qualify. System callbacks check live QMI/MMIO
ownership, registered PIO transport without BAM DMA, RPM_ACTIVE, AWAKE/IDLE and
no pending/running bringup work under SSR lock. They preserve the QMI handle,
power vote and controller state; resume validates retained invariants, returning
an error rather than guessing power-up repair. Default/other machines still use
force-runtime callbacks. Runtime `-EBUSY` remains. PIO thread behavior unchanged.

**Prepared:** one module compiled incrementally in the fixed build/release;
`slim-qcom-ngd-ctrl.ko` advertises the option. Reusable trial flag `894ecc812c49`
requires parked-audio and PMIC preparation. DF uses unchanged Image/DE DTB,
private sensor backend and DD FastRPC fix; fresh module staging includes NGD.
No live reload is attempted with retained audio firmware sessions.

**Next functional test:** collect DE actual recovery before installing DF; select
DF once. Verify actual baseline, parameterY, amps parked/closed PCM consumers and
active sensor clients. Run one guarded15-second PMIC alarm sleep: require real
BOOTTIME–MONOTONIC interval/IRQ, preserved controller software ownership and codec
enumeration, fresh sensor events and panel vblank, zero new DSP/SMMU/DPU faults.
No speaker playback or microphone/camera capture is needed for this trial.

**Limits:** powered retention is diagnostic, not proven energy saving, deep sleep,
normal desktop suspend, audio-after-resume or full P03. Do not claim acceptance
from preparation/build. Battery tests remain deferred. Known-good stays default,
trial selected once and existing automatic return retained.
