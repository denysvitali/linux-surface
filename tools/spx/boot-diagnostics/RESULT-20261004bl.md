`snd_soc_wcd934x.spx_persist_stream=1`, aligning WCD playback lifetime with the
parked DSP path. Known-good remained the persistent default.

and DP4 transport and enable registers passed. Playback also successfully reused
the persistent SlimBus stream, without BK's channel-reactivation timeout.

**The apparent missing DP4 was a diagnostic bug, not missing programming.**
The address macro lacked parentheses around its port argument. The snapshot's
`i ? 4 : 1` expression therefore read DP5 while labeling it DP4. This supersedes
the earlier BK/BL missing-port interpretation. Commit `c2909519b46c` fixes the
macro family;25 compile-time address checks passed. It finished building at20:50,
but was not loaded before the unexpected restart. Module reload without removing
the WSA codec also left default analog shadows and no PA/RDAC events; future
reloads must reset WSA software state while retaining the WCD provider.

Every test parked the amplifiers and restored mic routes/PM. Powerdown-before-PCM
teardown still leaves SoundWire FIFO/stream state needing controlled reload and
recovery. Capture ASM parking works; the known ADM capture COPP close timeout
remains. A01/A02/A03 stay open: actual speaker output has not been measured yet.
