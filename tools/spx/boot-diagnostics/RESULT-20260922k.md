# SPX bounded SPI-HID startup trial K — final scoped result, 2026-09-22

**The new bounded retry path ran, but touch/pen did not enumerate.** K made
three startup reads, received an all-zero header each time, and stopped
polling at its deadline. No raw SPI HID device or IPTSD instance appeared.
The stage-4 audio, graphics, Wi-Fi and remoteproc baseline passed through
**605.12 seconds uptime**. All **279 archived files** were independently
rehashed before this document was finalized. Mainline was intentionally
retained after archive verification; no recovery return occurred.

The independent live sample at **184.60–211.25 seconds uptime** identified
boot `58d2ebe1-1b3d-4b75-aa1e-d0ff2d8b9562`, attempt `20260922k`, release
`7.3.0-rc2-spx-mainline-20260922k+`. K is a distinct build containing the
[bounded SPI-HID startup fix](TOUCH-KERNEL-FIX-20260922.md). Audio remains at
stage 4; DTB and runtime policies remain unchanged from J. GRUB retained
`saved_entry=spx-known-good`, with empty `next_entry`; no EFI `BootNext` was
set. See [K preparation](PREPARED-20260922k.md) for exact artifact provenance.

timer. At the independent check, `spx-active-port-fallback.timer` was active,
due at monotonic **1331.820336 seconds**; the original long-return timer was

pin Y, zero stage 5/6/7 substeps, child runtime suspension with active time 0,
running modem/CDSP/ADSP and connected Wi-Fi. Taint remained zero. The
archived kernel journal still contains exactly three startup polls, one
startup-poll timeout and one modem startup, with no generic reset attempt or

the SPI controller IRQ count is six. These counters accompany the failed
reads; they do not independently establish the underlying cause. The final
archive includes the loaded module's build-ID note, the installed build ID
and vermagic, agreeing with the independent live check above.

The bounded retry mechanism executed as intended, but K's input component
failed. Hardware recovery and physical touch/pen remain unverified. The next
input diagnostic requires a separately reviewed fresh boot; this result does
not justify blindly replaying K or advancing audio stages live.
