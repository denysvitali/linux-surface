# CA: USB-C forwarding restarts and external scanout recovers

Boot `9349d90b-0cdc-4363-8d80-1f45bc4b9c9d`, kernel
`7.3.0-rc2-spx-mainline-20261004bg+`. Same kernel, modules and DT as BZ;
no new kernel build. No audio, camera or microphone capture ran. U02–U04 stay
open because physical output/hotplug/orientation/PD/resume remain unverified.

**Test:** early forwarding starts at11.626s and receives real attached-dock
events. Once startup finishes, `trial.py usbc-reload` removes only
`surface_aggregator_usbc`, checks the existing display, reloads that module,
then observes30seconds. MSM and PHY stay bound; no synthetic HPD or firmware
GET is sent. Remove/load both return0 and the subscriber binds again.

**Observed:** before, while unloaded and after reloading, DP/eDP report
connected/enabled, external EDID is valid and external vblank advances. The
new subscriber is ready at132.384s and receives real disconnected132.667s,
connected135.189s, disconnected135.191s and connected135.303s notifications,
all orientation0/link4. This is a disconnect/reconnect sequence, so the
three active snapshots do not prove uninterrupted output.

After settling, GNOME again extends to Samsung S34J55x3440×1440@49.987Hz;
DRM has an active external framebuffer. Fresh consecutive vblank samples
69→70→71 have intervals19.994ms and20.012ms. No frame-done timeout, USC ACK
failure, oops or DP training error appears in the collected startup/reload log.
BZ's single startup timeout did not recur on this unchanged driver; its cause
remains unresolved rather than fixed.

**Meaning/next:** this setup recovers display scanout and event delivery after
subscriber restart without physical replug. It does not establish guaranteed
current-state replay, physical hotplug/orientation coverage or visible pixels.
Park unchanged USB-C trials until those physical tests or a supported new fix
are available. Other port features can advance meanwhile.

Evidence: `/var/lib/spx-boot-diagnostics/functional/20261005ca/usb-c/` contains
`reload.json`, phase DRM states, reload/full kernel logs, full journal and
`settled-vblank.json`. The original `scanout_preserved` field means active
snapshots only; the tool now labels this `scanout_at_all_snapshots`. Its original
zero-relative query can return a stale idle timestamp; the settled check waits
for each new frame and provides the50Hz measurement above. No artifact is
reinterpreted as proof of continuity. Known-good default/empty next_entry and
900-second automatic return remain; device/build locks are free.
