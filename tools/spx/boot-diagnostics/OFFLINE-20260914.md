## Watchdog node added to the same worktree

`sc8180x.dtsi` now carries the missing `watchdog@17c10000`
(`qcom,apss-wdt-sc8180x`, `qcom,kpss-wdt`, `clocks = <&sleep_clk>`,
`GIC_SPI 0`). The binding already listed `qcom,apss-wdt-sc8180x` and
`sc8280xp.dtsi` had the equivalent node, but `sc8180x.dtsi` never did, so the
port never probed a platform watchdog. The node matches the binding's own
example and the sibling SoCs; it is not a guessed address, and the same node
has driven `/dev/watchdog0` on this device from the 6.18 speaker DTBs.

The rebuilt DTB passes `CHECK_DTBS` with no warning for the new node (the 40
other warnings in that file are pre-existing). This change was not part of the
PERST commit recorded above and carries no runtime validation yet. It is the
kernel half of the pre-kernel recovery candidate described in RECOVERY.md,
which is the prerequisite for the first experimental boot.
