## What changed

"You need to build a feedback loop. I can't be around to tell you if it worked

are private; routes are restored and physical amplifier powerdown is checked.
Twenty-two offline tests pass. This does not calibrate sound pressure or prove
physical channel placement, useful volume, or desktop integration.

## Meaning and next step

The microphone can now provide feedback without a listener. Speaker output is
still unverified: A01/A02/A03 remain open. Working6.18 feedback explicitly enables
`snd_soc_wcd934x.spx_persist_stream=1` before first playback; BK had it disabled
while AFE/ASM/COPP remained parked. Capture-first ordering is known working.
There is no proven live recovery for this stale SlimBus state; codec-only reload
also has a clock-provider lifetime hazard. BL is installed with only that boot
setting added and one consumed-once feedback test queued after startup. It keeps
the same kernel/modules, known-good default and900s automatic return.
